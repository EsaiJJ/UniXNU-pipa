# The Adreno 650 images (a650_*) are the shared SM8250-AC vendor firmware. The digests below were measured on this
# pipa unit's /vendor/firmware through the booted ColorOS port (not yet cross-checked against the stock super.img):
# a650_gmu.bin, a650_sqe.fw and a650_zap.b00/.b02 match the TB-J716F values, but a650_zap.mdt, .b01 and .elf are
# device-signed and differ, so the pipa values are recorded here.
#
# The QCA6390 and Bluetooth digests come from the official pipa fastboot ROM
# pipa_global_images_OS2.0.16.0.UMZMIXM_14.0 (HyperOS 2.0.16, Android 14): NON-HLOS.bin and BTFM.bin are FAT16
# images. The Bluetooth pair is byte-identical to the live /vendor/bt_firmware copy. The Wi-Fi config comes from the
# live /vendor/etc/wifi/qca6390 (ColorOS port); unpack the stock super.img if a stock digest is needed.
#
# The touch firmware is not in /vendor; it is built into the stock boot.img kernel, whose built-in firmware table
# matches panel m82 42 02 0b (display-maker 0x42 -> the CSOT image; the _tm image belongs to display-maker 0x36
# panels).
#
# Extract with scripts/extract-stock-firmware.py (host side, no tablet needed) or scripts/extract-pipa-firmware.py
# (booted tablet). The blobs stay outside Git; this file publishes only their digests and provenance.
